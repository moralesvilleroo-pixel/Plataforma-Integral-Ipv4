# SubnetPro (prototipo web)

Sitio estático: no necesita `npm install` ni compilación.

- Probar en tu PC: abre una terminal en esta carpeta y ejecuta `python -m http.server 8000`, luego entra a http://localhost:8000
  (abrir index.html con doble clic no funciona: el navegador bloquea la carga del contenido desde archivos locales).
- Publicar: arrastra esta carpeta completa a https://app.netlify.com/drop
- Contenido y preguntas: `data/unidades.json`
- Cabeceras de seguridad: `_headers`
